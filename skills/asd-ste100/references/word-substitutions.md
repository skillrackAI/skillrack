# Common STE Word Substitutions

Well-established unapproved → approved pairs from the ASD-STE100 dictionary. This list is NOT the full dictionary (~900 approved words, ~2,000+ unapproved entries). For words not listed here, apply the STE principle — prefer the short, common, concrete word — and tag the finding `word (verify)` so the user can confirm against the official dictionary (free at asd-ste100.org).

Remember: Technical Names and Technical Verbs are exempt. Never flag part names, tool names, system names, or standard maintenance/manufacturing verbs.

## Verbs

| Unapproved | Approved |
|---|---|
| perform, carry out, accomplish | do |
| commence, initiate | start |
| terminate, cease | stop |
| utilize, employ | use |
| ensure, verify | make sure |
| rectify | correct |
| comply with | obey |
| indicate, demonstrate | show |
| fabricate, manufacture (general use) | make |
| require (= need) | need, must have |
| retain | keep, hold |
| assist | help |
| attempt | try |
| obtain | get |
| permit (verb) | let |
| notify | tell |

## Adjectives and adverbs

| Unapproved | Approved |
|---|---|
| frequently | often, frequently → "often" |
| adequate, sufficient (verify) | enough, satisfactory |
| additional | more |
| entire | all, complete |
| identical | the same |
| in excess of | more than |

## Structural red flags (not single words)

1. Any verb ending in **-ing** outside a Technical Name → restructure (rule V-2).
2. **Passive voice** ("is removed by", "was installed") in procedures → imperative or active (rule V-3).
3. **"There is/are", "It is … that"** openings → direct subject (rule S-7).
4. **Noun used for an approved verb**: "make a selection of" → "select"; "carry out an inspection" → "do an inspection" only if "inspect" is not the approved form — prefer the approved verb when one exists (rule V-7).
5. **4+ noun cluster** → break with prepositions (rule N-1).
